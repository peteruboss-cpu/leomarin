LeoMarin — versiunea în limba română

Deschide index.html în browser. Nu este necesară instalarea.

index.html — texte, secțiuni și datele companiei
style.css — culori, fonturi, aspect și adaptarea pentru telefon
app.js — panoul lateral, animații și copierea datelor
drive.jpg — fotografia principală

Păstrează toate fișierele în același dosar. Salvează textele în UTF-8.
Fontul Manrope se încarcă de pe Google Fonts când există conexiune la internet; altfel se folosește Arial.
Fotografie ilustrativă: https://images.unsplash.com/photo-1449965408869-eaa3f722e40d

Для просмотра откройте index.html двойным нажатием.
Для изменения текста откройте index.html в любом текстовом редакторе.
Дизайн редактируется в style.css, поведение — в app.js.
Сохраняйте все файлы в одной папке. Установка и сборка не нужны.
